## 路线热图语义修正

> 是骑行路线的热图，骑行过的轨迹

`mobile-05-distance-manifesto-v2.html` 中的“骑行热图”专指真实 Strava `summary_polyline` 的地理轨迹叠加，不使用日期方格或随机热力点。只绘制 2026 年 105 条户外 `Ride`；1 条 `VirtualRide` 因没有真实地理道路语义而明确排除。重复经过的路线以更高亮度呈现。

## PC / 移动端双端适配

> 可行，同时需要自适应PC端和移动端都支持。大字间距不要重叠

继续在 V3 上迭代，不改变 Distance Manifesto 的视觉母题。375px 移动端保持单列阅读，960px 以上进入宽屏数据杂志布局：常驻章节导航、十二栏内容网格、路线图与活动列表并列、纪录与目标并列、训练证据双栏、画册弹层扩大。中文巨型标题不再套用紧凑西文行高，统一使用安全行高、轻微负字距与受控断行，避免上下行笔画相撞。

## GitHub 式年度日历

> 改为github方案的

全年骑行日历从“12 行月份 × 31 列日期”改为 GitHub Contributions 式结构：横轴按连续周推进，纵轴固定为星期，月份标在顶部。仍保留里程/爬升切换、真实每日骑行汇总和 Distance Manifesto 的橙色阶；移动端横向滚动，PC 端完整铺开。这里借结构而非品牌，不把骑行数据称为 GitHub contributions。
